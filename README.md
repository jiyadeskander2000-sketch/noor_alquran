# نور القرآن الكريم

تطبيق Flutter للمصحف والأذكار والاستماع ومواقيت الصلاة، بواجهة عربية تتكيف مع الهاتف والآيباد.

## المحتوى

- بيانات المصحف في `assets/data/quran.json` وبيانات السور في `assets/data/surahs.json`، وتشمل 114 سورة و6236 آية.
- ملف بناء البيانات `build_quran_dataset.js` يوضح مصدر النص العثماني والتفسير الميسر المستخدمين: AlQuran Cloud (`quran-uthmani` و`ar.muyassar`). راجع شروط المصدر قبل إعادة توزيع البيانات.
- الأذكار وأدعية ختم القرآن موجودة في `assets/data/azkar.json`.
- البحث يدعم إزالة التشكيل وتطبيع بعض أشكال الحروف العربية. التفسير المرفق مورد معرفي للمراجعة، وليس ضمانًا لصحة مطلقة أو بديلًا عن الرجوع إلى أهل العلم.

## مواقيت الصلاة

افتح «الصلاة»، ثم اختر موقع الجهاز أو مدينة جاهزة أو أدخل إحداثيات مدينتك. اختر طريقة الحساب المناسبة، ومنها أم القرى، وحدد مذهب حساب العصر. الحساب يعمل محليًا، وتحتاج قراءة موقع الجهاز إلى إذن المستخدم؛ يمكن بدلًا منه إدخال الموقع يدويًا.

زر «تفعيل تنبيهات الصلاة» يطلب إذن الإشعارات ويجدول مواقيت الأيام السبعة التالية، ثم يجددها عند العودة إلى التطبيق. دقة التنفيذ وظهور التنبيهات في الخلفية يتأثران بإعدادات توفير الطاقة وأذونات نظام الهاتف. التنبيه يستخدم صوت الإشعار الافتراضي، ولا يشغّل تلقائيًا تسجيل أذان الحرم. يمكن استيراد ملف صوتي يملكه المستخدم وتشغيله تجريبيًا داخل التطبيق.
